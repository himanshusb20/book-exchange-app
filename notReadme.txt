Project- books-exchange

How it works-

1. Register or log in
Students create accounts and manage their profiles.

2. List or discover books
Owners add books; other students search and filter listings.

3. Send a book request
The interested student submits a sale or exchange request.

4. Approve or reject
The owner decides; both students can see the request status.

5. Complete the transaction
Record the completed sale or exchange in the transaction history.

Techstack-

React Router
Tailwind CSS
